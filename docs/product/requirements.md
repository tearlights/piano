# 第一阶段产品需求

更新日期：2026-08-12

## 用户任务

用户将自有或获授权的静态琴谱转化为结构化、可播放、可解释并可编辑的个人练习材料。

直接用户是钢琴学习者。不同能力阶段共享同一条产品主线，不为教师或机构另建独立工作流。

## 交付阶段与当前状态

| 能力层 | 当前状态 | 当前验收边界 |
| --- | --- | --- |
| 本地琴谱接入与阅读 | 已有原型，仍需补齐验收 | 已实现 PDF/图片导入、阅读及部分管理能力；阅读状态持久化、备份完整性和自动化测试仍不完整 |
| MusicXML 展示与小节定位 | Debug Spike 已验证 | 配套测试 XML 可解析摘要、以 alphaTab 渲染并定位小节；尚未接入正式琴谱数据和持久化 |
| 结构化编辑与修订 | 当前工程优先，未实现 | 先基于测试 MusicXML 完成 ScoreIR、错误校正、校验、重渲染与修订保存 |
| OMR 与原谱对照校正 | 第二周交付目标，未实现 | 在已预留数据接口后接单页输入、转换、置信度、原谱位置映射与失败恢复 |
| 片段播放、解释与练习版本 | 后续，未实现 | 依赖可信结构、稳定音符标识和统一时间轴 |
| MIDI 跟弹反馈 | 后续，未实现 | 依赖目标片段、播放时间轴和演奏数据模型 |

下列“功能范围”描述第一阶段目标，不应据此推断功能已经实现。

## 功能范围

### 谱面接入与学习资料

- 系统文件选择器导入 PDF 与图片；支持一次选择多份文件。
- 最近阅读、收藏、文件夹、标签、关键词搜索。
- 自动生成可选封面缩略图；允许修改曲名、作者与备注。

### 阅读器

- 单页、连续滚动、横屏双页（双页仅适配足够宽的设备）。
- 双指缩放、拖拽、适合宽度/高度、一键恢复。
- 记忆页码、缩放、阅读模式与屏幕方向偏好。
- 书签；批注作为后续小版本功能预留数据接口。

### AI 乐谱理解与片段练习

- 将边界清晰的单页钢琴谱识别为音符、节拍、小节、左右手和重复记号等可计算结构，并以可校正草稿呈现。
- 支持按小节或选区播放原速/慢速、循环、左右手切换和谱面高亮。
- 针对用户选中的片段解释节奏、调号、反复记号与练习重点，并提供可核对的谱面依据。

### 个人化练习版本

- 比赛 MVP 在移调、可演奏性适配、技术化简和指法初稿中至少实现一项；正式投入实现前由真实学习者验证和 Demo 可行性共同确定优先项。
- 建议以差异预览呈现，支持逐项采纳、修改、撤销和保留原谱。
- 原谱和派生练习版本并存保存。
- 原始谱面默认本地保存；若调用模型或服务，须明确告知、取得授权并最小化传输。

### MIDI 跟弹与演奏反馈

- 支持连接兼容 MIDI 的电钢琴；用户需显式选择练习片段、速度和模式。
- 将 MIDI 按键事件与目标片段的结构化乐谱对齐，反馈音高匹配、节奏偏差、漏音、多音和连续性。
- 反馈必须定位到具体小节或拍点，并给出可执行的下一步练习建议。
- 首期不对踏板、力度、音色、手型、自由速度和艺术表现作全面评价。
- 演奏记录默认本地保存；上传、分享或模型训练用途须独立取得用户授权。

### 节拍器

- BPM 30–300，2/4、3/4、4/4、6/8，播放/暂停与音量。
- 强拍与弱拍区分；支持保存预设。

### 备份与恢复

- 导出完整库、指定文件夹或单份琴谱。
- 导入 `.gpiano` 包前显示冲突和空间检查。

## 验收重点

- 用户能校正识谱草稿，并按选中小节完成慢速、循环或左右手播放。
- 个人化建议明确呈现结构依据、音乐表达与难度取舍，且支持撤销。
- 用户能连接兼容 MIDI 电钢琴，对选中片段完成跟弹并理解基础匹配反馈。
- 大 PDF 打开、缩放、翻页不阻塞界面，也不打断练习流程。
- 备份恢复后原谱、派生练习版本、阅读进度、书签和用户标记对应正确。
