# 视觉与自适应规范（练习工作区基础）

本规范中的谱面阅读原则同样适用于结构化谱面、播放高亮、AI 建议和 MIDI 反馈。当前工作区的优先级是：关键谱面始终可见，练习反馈以短暂、可定位、可关闭的方式出现。

## 已确定方向

- 首发优先竖屏体验；横屏属于后续增强，不是首版主要验收目标。
- 界面风格简约、安静、低干扰，避免高饱和大面积颜色。
- 阅读器内容按原始比例显示：在可用阅读区内，宽度或高度至少有一边填满；不拉伸、不裁切琴谱。
- 手机与平板都应可用，布局通过尺寸等级自适应，而非按设备型号分支。

## 阅读器版式规则

设可用阅读区域为 `viewportWidth × viewportHeight`，琴谱原始尺寸为 `contentWidth × contentHeight`。

### 默认：适合宽度

- 缩放比例为 `viewportWidth / contentWidth`。
- 琴谱宽度填满阅读区，高度可超出并纵向滚动。
- 这是竖屏、单页 PDF 与大多数图片琴谱的默认模式。

### 适合高度

- 缩放比例为 `viewportHeight / contentHeight`。
- 琴谱高度填满阅读区，宽度较窄时以居中留白呈现。
- 适用于单页浏览、横向内容或用户明确选择的场景。

### 约束

- 最终缩放比例由用户选择的模式决定，不允许变形填满双方向。
- 顶部/底部控制栏出现时，必须重新计算可用阅读区，不能盖住关键琴谱区域。
- 图片背景与琴谱边缘保持足够区分；不添加会干扰阅读的阴影或纹理。

## 色彩角色

颜色名称描述角色，具体色值在创建 Compose 主题时落地，并需检查无障碍对比度。

| 角色 | 用途 | 建议倾向 |
| --- | --- | --- |
| `Canvas` | 页面大背景 | 微暖的浅灰白，避免纯白刺眼 |
| `Surface` | 卡片、底部导航、抽屉 | 比背景略亮或略深的低对比中性色 |
| `Primary` | 主要按钮、选中态、焦点 | 低饱和蓝灰或鼠尾草绿 |
| `Secondary` | 标签、辅助强调 | 浅灰蓝、浅米色等低饱和色 |
| `OnSurface` | 主要文字和图标 | 接近黑的深灰，保证对比度 |
| `Outline` | 分隔线、未选中轮廓 | 轻灰色，不用强边框 |
| `Error` | 错误和破坏性操作 | 柔和红色，但文字对比必须达标 |

琴谱内容不套用应用主题着色，始终按源 PDF/图片渲染。

## 字体与密度

- 使用系统 sans-serif，避免首版引入网络字体或额外包体。
- 标题层级少：页面标题、分区标题、正文、辅助信息四级即可。
- 触控目标不小于 48dp；阅读器的低频功能不常驻显示。
- 页面横向间距以 16dp 为基础，紧凑设备可缩至 12dp；列表条目以清晰可扫读优先。
- 曲谱库封面使用圆角缩略图；琴谱阅读内容本身不强制圆角裁切。

## 动效与反馈

- 控制栏显示/隐藏使用短淡入淡出，避免滑入遮挡用户视线。
- 导入、渲染和备份使用明确进度和文本状态，不以无限动画代替反馈。
- 尊重系统“减少动态效果”设置。

## 首版验收场景

1. 360dp 宽的竖屏手机：曲谱可适合宽度阅读，工具栏不挤压核心操作。
2. 竖屏平板：内容不拉伸，列表与设置保持舒展，阅读区仍以琴谱为中心。
3. 深色系统主题：应用界面可切换深色，但 PDF/图片保持原样且边界清晰。
