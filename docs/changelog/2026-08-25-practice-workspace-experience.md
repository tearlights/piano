# 2026-08-25 练习工作区体验

## 工作区 MIDI 会话

- MIDI 设备连接和跟弹录制从设置弹窗提升到练习工作区生命周期。
- 收起设置面板不会断开设备或结束跟弹；谱面底部提供紧凑的设备、进度、完成和取消控制。
- 录制中切换到底部其他工作区时，要求用户保存、放弃或留在当前页面；离开后释放设备。
- 新增 MIDI 工作区退出状态回归测试。

## 实时谱面反馈

- 跟弹开始前增加一小节倒计时，随后沿固定速度选段时间轴推进。
- 谱面自动跟随当前小节，并以黄色目标、绿色正确、红色错误/漏音音名提供实时反馈。
- 实时反馈与最终报告共用 `PerformanceMatcher`；新增增量反馈与固定时间原点测试。

## 双头小节选段

- 顶部小节 Chip 列表改为 Material 3 双头范围滑块。
- 起点、终点均显示精确小节数并支持 `− / +` 精调，保留“当前小节”和“全篇”。
- 选段起止与谱面查看焦点分离；拖动中不滚动谱面，松手后才定位。
