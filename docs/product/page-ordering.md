# 页面顺序调整（支撑能力）

页面顺序调整服务于原谱、识谱草稿和派生练习版本的资料完整性；它不替代练习工作区中的结构化选段与版本管理。

页序移动必须在同一个数据库事务内读取当前显示顺序并交换相邻页，只接受 `-1`（上移）或 `1`（下移）。UI 传入的旧 `displayIndex` 不能在事务外预读后直接写回；快速连续操作应依次基于最新顺序执行。阅读器持续订阅同一个按 `scoreId` 创建的 Flow，页数减少时将当前页收敛到新范围。

每份琴谱都有一张独立的页序表。`sourceIndex` 表示原始 PDF/图片页，`displayIndex` 表示用户阅读顺序；调整顺序不修改原文件。

首版交互：阅读器“更多”→“调整页面顺序”，以页码列表显示；每项可上移、下移，且可恢复原始顺序。后续在 PDF 缩略图渲染稳定后升级为长按拖拽。

导出 `.gpiano` 时须包含页序表。
