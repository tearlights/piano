# .gpiano 备份完整性审计

更新日期：2026-08-12

状态：当前实体已由 v3 覆盖；未来实体继续按本清单验收。

当前格式版本 3 已覆盖曲谱基础元数据、收藏、原始文件/图片页、文件夹、页面顺序、书签、结构化 MusicXML 修订和脱敏 OMR 任务，并兼容格式版本 1/2。远端任务 ID和访问令牌不会导出；ReadingState、派生练习版本和 MIDI 演奏反馈尚未实现，不能声称备份了这些不存在的数据。

完整备份必须覆盖：

- 曲谱元数据与原始 PDF/图片文件。
- OMR 产生的结构化乐谱、位置映射、置信度与人工校正结果。
- OMR 任务的本地状态、输入摘要、诊断与结果关系，但不包含凭据或不可迁移的远端 ID。
- 派生练习版本、改编参数、差异信息和版本关系。
- 文件夹及曲谱的 `folderId` 归属。
- 收藏状态。
- 页面顺序表 `score_pages`。
- 书签表 `bookmarks`。
- 用户选择导出的 MIDI 演奏会话与匹配反馈。

恢复必须在写入前校验格式，文件仅能写入 App 私有受控目录；未知或损坏条目不能破坏现有学习资料。原谱应先于结构化乐谱、派生版本和演奏记录恢复；可选演奏记录损坏时应可跳过恢复。
