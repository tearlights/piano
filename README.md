# Gpiano

本地优先的 Android 智能钢琴学习伙伴。Gpiano AI 以 OMR、MusicXML、AI 练习指导、可编辑练习版本和 MIDI 跟弹反馈，将用户自有或已获授权的静态琴谱转化为可听、可看、可练、可调整、可校准的个人练习材料。
