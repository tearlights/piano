# .gpiano 备份完整性审计

更新日期：2026-08-12

状态：完整备份验收清单，不代表当前实现已经满足。

当前格式版本 1 只覆盖曲谱基础元数据、收藏状态和原始文件。文件夹、页面顺序、书签、阅读状态以及未来结构化练习数据仍缺失，因此现有 `.gpiano` 应描述为“基础导入导出”，不能描述为完整库备份。

完整备份必须覆盖：

- 曲谱元数据与原始 PDF/图片文件。
- OMR 产生的结构化乐谱、位置映射、置信度与人工校正结果。
- 派生练习版本、改编参数、差异信息和版本关系。
- 文件夹及曲谱的 `folderId` 归属。
- 收藏状态。
- 页面顺序表 `score_pages`。
- 书签表 `bookmarks`。
- 用户选择导出的 MIDI 演奏会话与匹配反馈。

恢复必须在写入前校验格式，文件仅能写入 App 私有受控目录；未知或损坏条目不能破坏现有学习资料。原谱应先于结构化乐谱、派生版本和演奏记录恢复；可选演奏记录损坏时应可跳过恢复。
