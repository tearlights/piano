# 2026-08-12：结构化乐谱片段播放交接

## 已完成

- 新增 `PlaybackPlan`，以 960 PPQ 将 ScoreIR 的小节、声部内位置、时值、音高与手别投影为统一播放计划；不建立第二套业务小节编号。
- 工作区支持连续小节范围、50%/75%/原速、循环、双手/右手/左手、暂停、继续与停止。
- alphaTab 播放器使用加载 MusicXML 的公开 tick cache 确定实际起止时间，应用侧计划负责选择校验、时长估算与手别语义。
- 播放范围高亮、节拍光标、顶部当前小节和底部播放状态共享 alphaTab 时间轴。
- 修复循环边界事件被误判为停止的问题；打开范围面板会先停止旧计划，避免修改设置后继续播放旧片段。
- alphaTab 升级到 1.8.3；同步升级 Kotlin 2.2.20、KSP 2.2.20-2.0.4、Room 2.8.4、AGP 8.12.3、Gradle 8.13 与 compileSdk 36。数据库版本、schema 和 targetSdk 未变化。
