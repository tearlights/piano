# 当前项目状态

最后更新：2026-08-26

## 一句话结论

Gpiano 已完成可运行、可验证的比赛 MVP 技术闭环：用户可把单页图片琴谱转换为可校正的 MusicXML/ScoreIR，在结构化工作区中播放、理解、修改、导出，生成并继续校正独立练习版本，并以本地 MIDI 演奏事件获得选段级反馈。当前工作进入“整理验证证据、开展真实学习者体验验证”的阶段。

## 当前闭环

```text
单页图片
  → Audiveris OMR 任务
  → MusicXML / ScoreIR 校验与待校正草稿
  → 原谱对照、刻谱、校正、修订历史
  → 选段播放 / 本地结构指导 / 授权 AI 问答
  → 独立派生练习版本、差异审阅、试听与导出
  → MIDI 跟弹、事件级反馈、练习记录与备份
```

原谱、主谱修订、派生版本和练习记录均默认保存在本机；每条外发 AI 请求都要求用户针对当前选段再次确认。

## 已验证事实

1. 设备 `DXA800A5LAWBJ509` 上完成“导入图片 → OMR → 草稿 → 原谱对照 → 试听 → 校正 → 撤销”的真实流程；转换失败不会覆盖原谱。
2. 同一设备完成工作区强制结束进程后的恢复：重新进入“练习工作区”可打开最近选择的 24 小节结构化谱。
3. 主谱导出得到 125,801 字节 MusicXML 4.0.3 文件，XML 解析成功。
4. 备份导出得到 `.gpiano` v5 包；清单文件与 SHA-256 全部匹配，包中包含 1 份谱、2 个结构、7 个主谱修订、2 个派生版本（后续验证中新增）、1 次跟弹尝试和 6 个原始 MIDI 事件。v5 往返恢复后，Room 外键检查无输出。
5. AI 失败分支会显示具体原因并保留主谱；成功分支可创建独立草稿版本。该验证使用隔离假模型，只证明协议、授权、校验与 UI 闭环，不证明模型教学质量。
6. 选段 MIDI 导出经独立解析：SMF format 0、单轨、960 PPQ、按速度写 tempo、音符起止成对，延音不会被重复导出为第二次起音。

## 当前明确不作为完成结论的事项

- 不宣称 OMR 对任意复杂乐谱准确；当前只验证单页清晰图片的技术链路。
- 不将单次 MIDI 匹配包装成全面演奏评分；不评踏板、力度、手型、音色或艺术表达。
- 不将屏幕测试输入写成真实电钢琴验证；真实设备连接改列为后续进阶兼容性工作。
- 不将假模型集成测试写成真实模型的教学有效性结论。
- 未完成真实学习者完整流程测试，尚不能据此宣称产品效果或付费意愿。
