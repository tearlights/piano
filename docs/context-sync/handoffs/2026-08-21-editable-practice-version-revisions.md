# 2026-08-21：派生练习版本独立修订交接

## 当前可运行状态

核心链路已扩展为：真实图片 OMR → 主谱校正 → 派生练习版本 → 派生版继续校正/历史/撤销重做 → 播放、指导、跟弹、MusicXML 与完整备份。当前数据版本为 Room v11、`.gpiano` v6。

统一后端由 `scripts/start-backend.sh` 启动，本机私密配置只在 Git 忽略的 `scripts/backend.local.sh`。当前模型为 `deepseek-v4-flash`，没有启用 Pro。

## 关键实现

- `PracticeVersionRevision` 与 `PracticeVersion.currentRevisionId` 组成独立派生修订链；基础候选用空指针表示。
- `PracticeVersionRepository` 负责原子写文件、事务切换指针、并发保护、历史、撤销/重做及有效版本恢复。
- 工作区根据当前是否预览派生版本，将校正、历史、撤销/重做、导出和各练习消费者路由到正确文档。
- 备份 v6 覆盖派生基础候选、当前指针、修订树及每份修订 MusicXML，兼容读取 v1～v5。
