# 练习工作区体验规范（比赛 MVP）

更新日期：2026-08-25

状态：已实现的练习工作区体验规范。

## 默认状态

直接打开练习工作区时默认先显示选谱页，最近练习排在最前，并提供曲谱库入口。用户显式开启“自动恢复上次练习”后，后续才直接打开最近谱；关闭后恢复默认选谱。打开具体谱后以“适合宽度”展示原谱或结构化渲染谱，识别、渲染、播放或设备连接时提供轻量进度与可恢复路径，不展示空白误导页。

工作区标题区提供“换谱”，切换前停止当前播放并关闭校正、试听、指导、版本、MIDI 与 AI 面板。新谱的选中小节和试听范围从第 1 小节重新建立，不能沿用上张谱的越界状态。

## 沉浸式操作

- 单击中央区域：显示或隐藏基础谱面控制栏。
- 选择小节后可打开试听面板；起点和终点均可直接点选，并提供“当前小节”“全篇”快捷范围，不使用逐次加减按钮。
- 控制栏自动淡出；用户拖拽、缩放、播放、校正或跟弹时不自动隐藏。
- 常用操作：片段播放、速度、循环、左右手、高亮、解释与 MIDI 连接。
- 低频操作：版本管理、导出、删除、授权与设备校准，放入更多菜单。

## 视觉规则

- 应用界面可随系统深浅色，但琴谱始终以原始内容为准。
- 控制栏使用半透明浮层，避免整条不透明色块压住琴谱。
- 当前选区、播放位置、加载、识别置信度和错误信息必须可读且不遮挡关键谱面。
- 小节入口和试听范围使用带稳定 key 的懒加载横向列表；长谱不一次性组合全部按钮。
- 谱面向下滚动再向上返回时必须恢复已回收的可见分片，不允许出现全白或局部消失。
- 横屏平板优先使用双页模式；手机横屏保持单页为默认。

## 容错

- 无法渲染的文件显示可理解原因，并提供“重新导入”而不是静默失败。
- 导入重复文件时让用户选择跳过、保留副本或替换元数据；不得自动删除内容。
- OMR 置信度不足时保留原谱，明确标示待校正区域；不得将草稿作为确定乐谱直接用于改编或演奏评价。
- MIDI 断连、延迟异常或匹配失败时保留当前练习状态，说明原因并允许重新连接、重新校准或关闭反馈。
- 页面重排、恢复原序或删除导致页数变化时，阅读位置自动限制在新的有效页范围；不得显示不存在的页码或因重组重复订阅页面数据。
