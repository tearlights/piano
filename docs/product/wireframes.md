# 低保真线框（历史 v0：本地阅读器阶段）

> 本文保留旧阶段的视觉与阅读交互参考，不作为比赛 MVP 的现行信息架构。现行方向见 `docs/product/information-architecture.md`、`docs/product/reader-ux.md` 和 `PROJECT_BRIEF.md`；当前应补充“结构化谱面选区、播放、AI 建议与 MIDI 跟弹”的练习工作区线框。

以下线框描述信息优先级，不代表最终视觉风格。

## 1. 曲谱库

```text
┌─────────────────────────────────┐
│ Gpiano                    [导入] │
│ [⌕ 搜索曲名、作者、标签]          │
│                                 │
│ 最近阅读                         │
│ ┌──────┐  贝多芬·献给爱丽丝  ›   │
│ │ 封面 │  第 2 / 4 页            │
│ └──────┘                         │
│                                 │
│ 全部琴谱                    排序 │
│ ┌──────┐  哈农练指法            │
│ │ 封面 │  PDF · 基础练习         │
│ └──────┘                         │
│                                 │
│  曲谱库       收藏      文件夹 设置 │
└─────────────────────────────────┘
```

空状态只提供一个明确主按钮“导入琴谱”，并说明支持格式。

## 2. 导入确认

```text
┌─────────────────────────────────┐
│ ← 导入琴谱                       │
│                                 │
│ [缩略图]  selected-score.pdf     │
│                                 │
│ 曲名  [ ____________________ ]  │
│ 作者  [ ____________________ ]  │
│ 文件夹 [未分类                 ›]│
│ 标签   [+ 添加标签]              │
│                                 │
│                     [取消] [导入]│
└─────────────────────────────────┘
```

元数据可跳过，导入过程不能要求用户填写。

## 3. 阅读器：默认沉浸状态

```text
┌─────────────────────────────────┐
│                                 │
│                                 │
│          PDF / 图片琴谱          │
│           适合宽度显示            │
│                                 │
│                                 │
│                                 │
│                            2 / 4 │
└─────────────────────────────────┘
```

单击中间区域显示控制层；缩放、拖拽不应误触发翻页。

## 4. 阅读器：控制层与节拍器

```text
┌─────────────────────────────────┐
│ ←  献给爱丽丝       ☆       ⋮   │
│                                 │
│          PDF / 图片琴谱          │
│                                 │
│ ─────────────────────────────── │
│ [‹]        2 / 4           [›]   │
│ [模式]  [书签]  [节拍器] [显示] │
└─────────────────────────────────┘

节拍器以底部抽屉打开：
┌─────────────────────────────────┐
│ 节拍器                           │
│         −     80 BPM      +      │
│       [2/4] [3/4] [4/4] [6/8]   │
│ 音量 ━━━━━━━━━━━━                │
│ [保存预设]                 [播放]│
└─────────────────────────────────┘
```

节拍器关闭抽屉后应保留极小状态提示，不常驻遮挡琴谱。
