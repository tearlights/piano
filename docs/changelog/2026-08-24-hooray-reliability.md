# 2026-08-24 Hooray 稳定性与体验修复

## alphaTab 播放时间轴

- 修复不规则 MusicXML 在后段小节无法试听的问题。
- 播放器不再比较 ScoreIR 与 alphaTab 的绝对 tick；手机试听的选段、跳转和循环边界统一使用 alphaTab 当前乐谱时间轴。
- 保留小节映射的越界、重复索引和无效范围检查。
- MIDI 跟弹目标与标准 MIDI 导出继续使用确定性的 `PlaybackPlan`，不把 alphaTab 私有时间轴写入持久化数据。
- 修复全篇播放时 alphaTab Android 内部滚动产生负动画时长并导致 App 崩溃的问题；关闭缺陷动画，由 Gpiano 在小节变化时安全跟随横/纵位置，保留播放游标和音符高亮。
- 保留 alphaTab 懒加载，在谱面回滑时转发其可见区域更新并补发布局/重绘，修复下滑后上滑谱面消失；真机完成三轮快速往返压力测试。
- 回退到声音正常的 alphaTab 1.8.3；崩溃由应用侧滚动处理器隔离，避免采用 1.8.4 音频尾部补零行为。问题谱生成 MIDI 经回归测试确认没有极短同键双触发。

## AI 服务安全

- 模型 provider 地址只允许解析到公网的 HTTPS 端点；HTTP loopback 仅能在显式开发开关下使用。
- 禁止 provider HTTP 重定向，避免跨主机重定向携带模型 API 密钥，并消除重定向后的内网 SSRF 路径。

## 本地数据库升级

- 修复 v1-v6 存量数据库升级时缺少 `scores.lastOpenedAt`、进入曲谱库后查询崩溃的问题。
- 数据库打开时显式启用 SQLite 外键，删除曲谱后关联结构、识别任务与练习数据会按 Room 声明级联或置空。

## 左右手识别

- 双 part 钢琴谱优先按 part 判定左右手，修复左手 part 的 `staff=1` 被错误归到右手、导致单手试听和练习过滤错误的问题。

## 练习工作区

- 进入工作区默认先选谱，按最近练习排序；自动恢复改为默认关闭的显式设置，并支持工作区内换谱和无谱时返回曲谱库。
- 试听范围改为直接选择起止小节，增加“当前小节”“全篇”快捷操作；小节与范围列表使用带稳定 key 的懒加载列表。
- 导航目标、自动恢复偏好和当前结构标识在配置变更后保持；最近练习偏好改为异步落盘，避免主线程同步写入。

## 编辑并发

- 校正、撤销/重做、修订切换和练习版本创建/状态/导出使用同步原子门闩，修复快速双击在同一帧启动多个写操作的问题。
- 操作异常、协程取消或文件选择器取消都会释放 busy 状态，避免工作区永久锁死。

## 阅读与页序并发

- 书签切换和页序移动改为 DAO 事务，快速点击不会在 Repository 层因读改写分离而丢失更新。
- Reader 与页序面板稳定复用按琴谱标识创建的页面 Flow；页面数量变化后当前页会自动回到有效范围。

## 工作区重组性能

- 播放 UI 状态声明为不可变；复用文档已有摘要，并缓存当前小节事件数量与校正事件列表，避免播放状态变化时反复遍历整谱。

## 备份大小边界

- 导出和导入统一采用 64 MiB 的备份 JSON 上限；导出在写目标文件前完成字节大小校验，修复大型备份“能够导出但无法导入”的自拒问题。
- 识别任务备份会剥离远端任务 ID、自由文本错误和诊断 JSON，只保留稳定错误分类与恢复所需状态。
- 备份恢复改为真正覆盖：单个 Room 事务先清空旧业务表再按外键顺序写入快照，空列表不再跳过；成功后清理旧快照独占文件。

## ScoreIR 数据边界

- 拒绝零/负时值、负起点、结束位置溢出、索引错位和同 voice/staff 事件重叠；标称小节 tick 全程使用 Long 运算，避免大拍数先发生 Int 溢出。
- 修改音符/和弦时值时同步补偿后续 `backup/forward`：本声部按新时值移动，其他声部 onset 保持不变。

## 文件与数据库一致性

- PDF/图片组导入的元数据改为 Room 事务；文件读取、分页或 DB 失败会清理本次 UUID 文件，扩展名不再信任提供方文件名。
- 删除曲谱及备份文件安装统一校验 canonical 路径必须位于 App 私有目录，拒绝受污染的绝对路径和 `..` 越界。
