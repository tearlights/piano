# ADR-0005：确立谱面理解与练习决策支持的产品主线

日期：2026-08-04  
状态：已接受

## 决策

Gpiano 的产品主线是谱面理解与练习决策支持：围绕用户正在练习的小节，提供可核对的节奏、演奏法、键位关系、段落结构与练习重点说明，并转化为下一步练习动作。

后续产品验证优先围绕用户在读谱时的具体理解障碍，例如节奏、三连音、连线、音高、段落与建议指法。作品接入、谱面呈现、学习状态和数据迁移属于支撑能力。

本 ADR 不预先决定分析功能使用规则引擎、人工标注、端侧模型或其他技术方案；也不改变默认不上传用户琴谱、无账号和本地优先的隐私边界。若引入识谱模型、云端分析或新的用户数据结构，必须另立 ADR。

## 原因

- 用户需要将眼前的琴谱读懂、弹对，并完成有效练习。
- 通用文件管理器和专业乐谱阅读器已经能较好解决存储、打开和组织问题；Gpiano 的差异应来自对练习过程的帮助。
- 当前已有的导入、阅读和本地保存能力可作为分析体验的可靠载体，但不能取代分析本身。

## 后果

- 产品定位、访谈问题和 MVP 排序以“分析是否减少用户理解/练习阻碍”为首要标准，并以 [第一周产品关键信息](../../比赛资料/第一周/output/产品关键信息.md) 作为比赛材料的优先依据。
- 成功指标以理解效率、练习动作质量和学习连续性为准。
- 在验证分析需求前，不承诺 AI 识谱、自动演奏评测或云端能力。
