## 发现的实现风险

- `.gpiano` 格式版本 1 仅覆盖曲谱基础元数据、收藏和原始文件，未覆盖文件夹、书签、页面顺序或未来练习数据。
- alphaTab 当前通过反射构造 `Uint8Array`；升级前需要回归保护。
- 练习工作区入口在主源码中，但测试 XML 仅存在于 Debug assets；发布前必须处理入口和正式数据源。
- 工程当前没有自动化测试。

## 下一可验证工作单元

先补充 `ScoreStructure`、`ScoreRevision`、位置映射和备份迁移设计，然后基于测试 MusicXML 完成：

```text
选择一个音符或时值
→ 修改 ScoreIR
→ 结构校验
→ 重生成 MusicXML
→ alphaTab 重渲染
→ 保存并可回退修订版
```

完成上述闭环后再接 OMR，不在用户可见流程中使用静态假谱、不可编辑占位或其他临时替代。
