# 信息架构与导航（v0）

## 顶层导航

第一版使用底部导航，保持四个入口，阅读器为全屏独立页面：

```text
曲谱库        收藏        文件夹        设置
  │
  ├── 搜索
  ├── 导入
  └── 曲谱详情 / 阅读器（全屏）
```

## 页面职责

| 页面 | 核心任务 | 首要操作 |
| --- | --- | --- |
| 曲谱库 | 找到最近或全部琴谱 | 搜索、导入、打开琴谱 |
| 收藏 | 快速回到高频曲目 | 打开、取消收藏 |
| 文件夹 | 按练习场景组织琴谱 | 新建、移动、打开文件夹 |
| 设置 | 配置阅读与数据行为 | 阅读偏好、导入导出、关于 |
| 阅读器 | 连续、不受干扰地看谱 | 翻页、缩放、书签、节拍器 |

## 关键流程

### 导入

```text
曲谱库点击“导入”
  → 系统文件选择器
  → 校验格式与可读性
  → 复制至私有存储、提取元数据/缩略图
  → 显示可编辑的曲名信息
  → 完成并打开，或回到曲谱库
```

导入失败时保留原始文件，不修改已有库；失败原因需可理解，并可重试。

### 阅读

```text
从任意曲谱列表打开
  → 恢复上次阅读状态
  → 单击琴谱呼出控制栏
  → 选择模式、页码、书签或节拍器
  → 自动保存状态
```

### 备份恢复

```text
设置 → 数据与备份 → 导出/导入 .gpiano
  → 选择目标或备份包
  → 校验空间、格式与冲突
  → 明确显示结果与可恢复的失败信息
```

## 导航原则

- 不为节拍器单独占一个顶层页：它服务于阅读，应从阅读器即时打开。
- 不在首版加入“在线库”入口，避免与本地优先定位冲突。
- 全部列表优先支持搜索与排序；文件夹是组织方式而不是唯一入口。
