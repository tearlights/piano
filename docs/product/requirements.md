# 第一阶段产品需求

## 用户任务

用户导入自己的琴谱，按分类找到它，在练习中清晰阅读，并在换机时完整带走资料。

## 功能范围

### 曲谱库

- 系统文件选择器导入 PDF 与图片；支持一次选择多份文件。
- 最近阅读、收藏、文件夹、标签、关键词搜索。
- 自动生成可选封面缩略图；允许修改曲名、作者与备注。

### 阅读器

- 单页、连续滚动、横屏双页（双页仅适配足够宽的设备）。
- 双指缩放、拖拽、适合宽度/高度、一键恢复。
- 记忆页码、缩放、阅读模式与屏幕方向偏好。
- 书签；批注作为后续小版本功能预留数据接口。

### 节拍器

- BPM 30–300，2/4、3/4、4/4、6/8，播放/暂停与音量。
- 强拍与弱拍区分；支持保存预设。

### 备份与恢复

- 导出完整库、指定文件夹或单份琴谱。
- 导入 `.gpiano` 包前显示冲突和空间检查。

## 验收重点

- 导入后原文件变动不影响 App 阅读。
- 大 PDF 打开、缩放、翻页不阻塞界面。
- 意外退出后仍能恢复阅读位置。
- 备份恢复后元数据、阅读进度、书签与源文件对应正确。
