# 2026-08-12：结构化修订持久化与备份 v2 交接

## 已完成

- 按 ADR-0011 将 Room 从 v6 升至 v7，新增 `score_structures`、`score_revisions`、外键和唯一索引，并统一所有数据库构造的迁移入口。
- MusicXML 修订以标准 `.musicxml` 文件保存在 `structures/<id>/revisions/`；数据库保存来源键、当前修订、父版本、操作审计和相对路径。
- 新修订先解析校验、写临时文件并提交，再在 Room 事务中插入版本和切换指针；失败删除新文件。撤销只切换指针，不删除历史。
- 工作区已使用持久化仓库，不再以进程内会话作为实际保存结果。
- `.gpiano` v2 覆盖当前已有的曲谱、页面文件/顺序、收藏、文件夹、书签、结构化乐谱和所有修订；逐文件记录大小和 SHA-256。
- 恢复先解压到缓存目录，检查路径、大小、哈希、关系和 MusicXML，再安装文件并在单个 Room 事务中合并；失败执行文件补偿。
- v1 解析路径保留；高版本、路径越界、重复条目、超限内容和损坏文件明确拒绝。
