# 当前项目状态

最后更新：2026-08-06

## 当前定位

Gpiano AI 的比赛 MVP 目标是验证“静态琴谱 → 结构化乐谱 → 个人练习材料”的可信闭环。详细定位以 `PROJECT_BRIEF.md`、比赛基础愿景和当前周输出材料为准。

## 已完成的基础能力

- Android Compose 工程、Kotlin、Room、本地私有文件存储与本地优先数据基础。
- PDF/图片导入、图片组处理、曲谱阅读、可视区域渲染、页面缓存与翻页过渡。
- 文件夹、收藏、书签、重命名、页面顺序、节拍器与 `.gpiano` 备份恢复。
- 产品、数据、隐私与 MIDI 跟弹边界已通过 ADR-0005、ADR-0006、ADR-0007 记录。
- 比赛资料已采用 `比赛资料/<周次>/input/` 与 `output/` 分层。

## 正在验证、尚未实现的比赛能力

- OMR 将单页钢琴谱转化为可校正的 MusicXML/结构化乐谱。
- 选段定位、分手、慢速、循环、播放高亮和结构化谱面解释。
- 派生练习版本、可编辑改编与差异预览。
- 兼容 MIDI 电钢琴的选段跟弹，以及音高、节奏、漏音、多音、连续性的基础反馈。

## 最近必须完成的工作

1. 收集至少 3 位真实用户对 OMR 校正、片段练习、改编与 MIDI 跟弹的需求和信任边界。
2. 为结构化乐谱、派生练习版本、演奏会话和反馈记录补齐数据模型、备份迁移与导入旧备份方案。
3. 确定比赛 Demo 使用的授权单页钢琴谱、目标 MIDI 设备和首个可编辑改编能力。

## 文档与工作流

- 新窗口先读 `PROJECT_BRIEF.md`，再读比赛基础愿景、当前周 `output/`、项目宪章、需求与 ADR。
- 本目录的旧历史交接文件可用于追溯已完成工作，但不得覆盖当前产品定位。
