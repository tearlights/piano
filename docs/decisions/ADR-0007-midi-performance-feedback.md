# ADR-0007：采用 MIDI 演奏输入形成跟弹反馈闭环

日期：2026-08-05  
状态：已接受

## 决策

在可信结构化乐谱和片段播放能力之上，Gpiano AI 支持通过 MIDI 接入兼容电钢琴，采集用户演奏事件，并与所选片段的目标 MusicXML/MIDI 表示进行匹配。

首期反馈仅覆盖可定义的练习维度：音高匹配、节奏偏差、漏音、多音和片段连续性。用户须显式选择目标片段、速度和练习模式；反馈以具体小节或拍点的可操作提示呈现。

## 原因

- MIDI 将真实按键行为转为可计算事件，使 AI 能基于用户实际演奏提供反馈。
- 对有一定基础的学习者，目标片段与实际演奏的差异是提升节奏、准确性和练习效率的重要依据。
- 基于同一结构化乐谱的播放、分析、改编和演奏反馈可共享位置与时间信息，形成连续体验。

## 边界

- MIDI 匹配不等同于全面演奏评分；首期不判断艺术表现、音色、踏板、手型和自由速度处理。
- 演奏记录默认本地保存；上传、分享或训练用途须独立获得用户授权。
- 识谱草稿未经用户校正或置信度不足时，不输出确定性的演奏评价。

## 后果

- 需要新增 MIDI 设备适配、演奏事件、目标片段、匹配结果和反馈记录等数据模型；实施前需补充迁移与导入旧备份方案。
- 比赛 MVP 先验证单一兼容电钢琴、边界清晰选段和基础匹配反馈，再扩大设备与评估维度。
