# ADR-0003：竖屏优先、自适应填充与低饱和视觉

日期：2026-07-29  
状态：已接受

## 决策

首发版本以竖屏阅读为主要体验。阅读器默认采用适合宽度，维持原始比例；琴谱宽或高至少有一边填满可用阅读区。应用使用低饱和、简约的视觉语言。

## 原因

- 竖屏是手机上的默认使用姿势，最利于尽早验证核心体验。
- 保持比例比双向铺满更符合乐谱阅读需求，避免音符和五线谱变形。
- 淡色、低干扰的界面能让琴谱成为视觉重点，并适合长时间练习。

## 后果

- 首版不以横屏双页为验收重点，但布局与状态模型不应排斥未来扩展。
- Compose 主题必须提供可访问的文字对比度，而不是只追求“颜色淡”。
- 阅读器需要实现适合宽度、适合高度和用户缩放三种不变形状态。
