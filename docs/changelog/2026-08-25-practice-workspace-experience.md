# 2026-08-25 练习工作区体验

## 工作区 MIDI 会话

- MIDI 设备连接和跟弹录制从设置弹窗提升到练习工作区生命周期。
- 收起设置面板不会断开设备或结束跟弹；谱面底部提供紧凑的设备、进度、完成和取消控制。
- 录制中切换到底部其他工作区时，要求用户保存、放弃或留在当前页面；离开后释放设备。
- 新增 MIDI 工作区退出状态回归测试。

## 实时谱面反馈

- 跟弹开始前增加一小节倒计时，随后沿固定速度选段时间轴推进。
- 谱面自动跟随当前小节，并以黄色目标、绿色正确、红色错误/漏音音名提供实时反馈。
- 实时反馈与最终报告共用 `PerformanceMatcher`；新增增量反馈与固定时间原点测试。

## 双头小节选段

- 顶部小节 Chip 列表改为 Material 3 双头范围滑块。
- 起点、终点均显示精确小节数并支持 `− / +` 精调，保留“当前小节”和“全篇”。
- 选段起止与谱面查看焦点分离；拖动中不滚动谱面，松手后才定位。

## 谱面点击选段

- 普通点击谱面小节会把命中的 alphaTab 小节索引回传到统一工作区状态。
- 点击只改变选段起点和查看焦点；终点按“保持或向起点收敛”规则处理。
- 校正面板打开时不会因谱面点击改变选段；新增坐标换算和选段规则测试。

## 顶部选段布局与点击边界修复

- 起点、终点、双头滑块、查看状态和“当前/全篇”快捷操作压缩到同一行，选段栏固定为 40dp，显著释放谱面空间。
- 起止端点相等时，`起点 +` 和 `终点 −` 仍可调整并自动保持合法范围。
- 谱面点击通过 Activity 级桥接观察，不拦截 alphaTab 滚动；视口外点击（底部导航、控制栏）不会改变小节选段。

## 回滑白屏回归修复

- 历史方案：曾在滚动停止后执行两阶段延迟布局/重绘恢复；后续确认根因是 alphaTab 在 layout dirty 时丢弃滚动 delta，已由 2026-08-26 的布局后偏移转发方案替代。
- 真机完成单轮及三轮快速上下滑，谱面恢复完整；不关闭懒加载。
## 2026-08-26 播放声部与底部回滑修正

- 修正 alphaTab 多 part 未声明 `midi-channel` 时的重复声道：播放前分配独立 channel，左右手静音不再互相影响。
- 切换手别、速度、循环或范围会停止当前播放，下一次试听使用新的播放计划。
- 修正 alphaTab 在 layout dirty 时丢失底部回滑 delta 的问题：布局完成后转发最新偏移，移除两阶段定时重绘。
## 2026-08-26 触底回滑缓存重建

- 针对“未触底正常、触底后回滑只剩当前页”的回归，检测触底到上滑的边沿并调用 alphaTab 公共 render 重建 lazy partial 缓存；恢复时保持用户当前滚动位置。
